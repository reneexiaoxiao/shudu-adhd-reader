舒读 v0.4.4 · Tabbit / Chromium 安装

1. 在 Tabbit 地址栏输入：chrome://extensions/
2. 打开页面右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 已加载过本目录时，只需点击「舒读」卡片上的「重新加载」
5. 刷新已打开的公众号、AI 内参、即刻或 X/Twitter 页面

如果 chrome://extensions/ 没有打开：
从 Tabbit 菜单进入「扩展程序」→「管理扩展程序」，再继续第 2 步。

推荐先用「专注」预设：980 px、18 px 字号、1.75 行高、0.68 段落间距、75% 强调密度。

普通文章页：打开「舒读」，点击「应用当前页面」。这个权限只用于当前标签页。

智能译读：展开「智谱 API 设置」，粘贴开放平台通用 API Key，点击「保存并测试」。
连接成功后点击「开启滚动译读」，或按 ⌥ + ⇧ + F。API Key 只保存在本机扩展存储中。
