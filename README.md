<h1 align="center">舒读 · 阅读与收藏</h1>
<p align="center">让网页更好读，让读过的内容留得下来。</p>

面向 Chromium 浏览器的开源扩展，支持 Tabbit、Chrome、Edge。当前版本 **0.7.2**，代码和 Logo 使用 MIT 许可证。它提供可调节的阅读辅助，不作 ADHD 医疗效果承诺。

## 能做什么

- 微信公众号、AI 内参和即刻桌面文章的单栏排版：宽度、字号、字体、行距与段距独立调整。
- 普通英文网页默认仅译读，不改变原网页排版；X / Twitter 不启用排版改动。
- 本地规则生成轻量语义强调，使用多种透明色。规则标注不等于大模型语义理解。
- 手动浅黄／浅绿标记、半透明蓝色细线、红色细波浪线与批注；不替换原文节点。
- 选中文字后默认只显示选区旁的小球，点击才展开划线批注菜单。
- 不用 Obsidian 也能划线、写评论和恢复批注；收藏同步独立开关，公开版默认关闭。
- 按需开启智谱 API 译读，保留 B2+/C1 学习表达，提供缓存和漏段补译。
- 阅读与收藏面板统一浅色／深色主题，并提供键盘焦点和减少动态效果支持。

## 使用条件

| 功能 | 是否需要额外服务 |
| --- | --- |
| 排版、语义强调 | 不需要，在浏览器本地运行 |
| 智能译读 | 需要自己的智谱开放平台 API Key，可能产生费用 |
| 保存、编辑和恢复本地划线／评论 | 不需要服务，使用扩展本地存储 |
| 网页／划线／图片收藏、批注同步到 Obsidian | 需要自行部署兼容的本机收藏服务 |
| 个性化消化、概念地图、视频导入 | 需要收藏服务另行实现相应能力 |

**本仓库发布的是扩展客户端，不包含作者的私人收藏服务、知识库、个人画像或系统启动项。** 默认不连接收藏服务。只有主动开启“收藏同步到 Obsidian”后，划线才会同时收藏，评论才会尝试同步；服务未连接时不会显示同步成功。服务接口见 [本机服务接入](docs/companion-api.md)。

### 不用 Obsidian：本机批注模式

保持面板顶部“收藏同步到 Obsidian”关闭即可。选中文字 → 点击小球 → 选择划线样式或“批注”。点击已有划线旁的批注点，可再次修改想法。收藏面板、收藏按钮和右键收藏入口会隐藏，不请求本机收藏服务；阅读与译读仍独立可用。

划线与评论按网址保存在当前浏览器的扩展本地存储中，重新打开原页时会尝试恢复；原文变化可能导致定位失败。不跨浏览器或设备同步，卸载扩展、清除扩展数据会丢失。当前未提供批注导出界面；存储最多保留 500 个页面、每页最近 300 条批注。

开关不会删除已有本机批注或 Obsidian 文件。之后开启同步不会自动补传关闭期间的批注；需要收藏的内容请重新选中并收藏。关闭前已发出的请求可能仍完成，关闭不会撤回已写入的文件。

## 安装

1. 下载 Releases 中的扩展包并解压，或克隆仓库。
2. 打开浏览器扩展管理页 `chrome://extensions/`，启用开发者模式。
3. 选择“加载已解压的扩展程序”，选择包含 `manifest.json` 的目录。
4. 刷新已打开的文章页。更新时替换扩展文件，在扩展管理页重新加载后刷新网页。

不需要构建。普通英文网页点击“开启滚动译读”按需注入；它不会因此套用微信公众号排版。

### 译读设置

在“阅读 → 智谱 API 设置”中填入自己的 Key 和可用模型代码，点击“保存并测试”。扩展使用 `https://open.bigmodel.cn/api/paas/v4/chat/completions`，不使用 Coding Plan 端点。默认模型代码是现有实现的 `glm-5.2`，实际可用性以账户权限为准，可自行调整。

Key 仅保存在本机扩展存储中，公开包不包含默认 Key。学习档位描述为核心概念、进阶阅读和强化学习，不包含作者个人考试成绩。

### 字体

公开包不附带中华薪火体或任何第三方字库。请自行取得合法使用授权后安装到系统；也可以将授权文件放入 `fonts/中华薪火体.ttf`。缺少字体时回退到系统字体，不影响其他功能。

## 快捷键

- `Alt / ⌥ + Shift + F`：开启或暂停滚动译读。
- `Alt / ⌥ + Shift + S`：收藏当前网页。
- `Alt / ⌥ + Shift + X`：收藏当前选区。

## 开发与验证

需要 Node.js 22 或更高版本运行测试，扩展运行本身不需要 Node.js。

```sh
node --test tests/*.test.mjs collector/*.test.mjs
```

主要模块：`content.js` / `reader.css` 负责排版；`translation*` 与 `reader-background.js` 负责译读；`collector/` 负责正文提取、划线、批注和本机服务通信；`ui-theme.css` 仅应用于扩展自身界面，不注入文章。

测试覆盖一键划线＋收藏、失败重试去重、图片选择、译文隔离、批注恢复和浮条避让等。单元测试不代替真实站点回归；动态网页更新仍可能影响正文识别。
