<h1 align="center">舒读 · ADHD 网页阅读器</h1>

<p align="center">让微信公众号、即刻、X / Twitter 和普通长文在显示器上更宽、更清楚、更容易抓住重点。</p>

舒读是一个本地运行的 Manifest V3 浏览器扩展，适用于 Tabbit、Chrome、Edge 等 Chromium 浏览器。它重排正文宽度与字号层级，提供更适合中文长文的字体、行距和段落节奏，并用半高透明马克笔区分重点、概念、行动、证据和程度词。

当前版本：**0.3.4**

## 功能

- 微信公众号正文宽度最高可调至 2400 px；窄窗口自动保留安全边距。
- 正文、列表、章节标题与多级标题使用独立字号阶梯，修复公众号原排版里标题反而更小的问题。
- 提供轻盈、专注、沉浸三种预设，也可独立调整字号、行距与段落间距。
- 本地规则自动加粗关键词，并以黄、蓝、绿、紫、粉五种半高马克笔区分语义。
- 自动折叠公众号里的空段和无装饰间隔容器。
- 即刻与 X / Twitter 使用无侵入的 CSS Highlight API，不替换 React 页面文字节点。
- 设置保存在 Chromium 扩展存储中；没有分析服务、遥测或正文上传。

## 安装

1. 下载或克隆本仓库。
2. 在浏览器地址栏打开 `chrome://extensions/`。
3. 打开「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择本仓库文件夹。
5. 刷新已经打开的公众号、即刻或 X / Twitter 页面。

```bash
git clone https://github.com/reneexiaoxiao/shudu-adhd-reader.git
```

普通 HTTP(S) 文章页不会自动运行：打开「舒读」面板，点击「应用当前页面」即可临时启用。

## 字体说明

公开仓库不包含「中华薪火体」字体文件，避免未经授权再分发第三方字库。扩展会先检测系统已安装的 `Sino-Torch` / `中华薪火体`，不可用时自动回退到苹方等系统字体。

如果你拥有该字体的合法授权，可将文件放到：

```text
fonts/中华薪火体.ttf
```

然后在扩展管理页点击「重新加载」。其他字体选项依赖操作系统已安装字体。

## 语义颜色

| 颜色 | 语义 |
| --- | --- |
| 黄色 | 重点、结论、本质 |
| 蓝色 | 概念、模型、方法与专有名词 |
| 绿色 | 行动、要求、建议与下一步 |
| 紫色 | 数字、证据、研究与案例 |
| 粉色 | 程度、层级与比较词 |

语义强调使用轻量本地规则，不等同于大模型理解；它优先保证隐私、速度与可预测性。

## 权限与隐私

- `storage`：保存阅读设置。
- `activeTab` 与 `scripting`：在你点击「应用当前页面」后处理当前标签页。
- 站点权限：让公众号、即刻和 X / Twitter 自动应用排版。

扩展不发起网络请求，不包含账户系统、广告、分析 SDK 或遥测。完整说明见 [PRIVACY.md](PRIVACY.md)。

## 开发与验证

项目不需要构建步骤，修改源码后在 `chrome://extensions/` 点击「重新加载」即可。核心文件：

- `content.js`：站点识别、排版与本地语义强调。
- `reader.css`：阅读版式、字体层级与马克笔效果。
- `popup.*`：设置面板。
- `manifest.json`：Manifest V3 权限与入口。

提交前至少确认：公众号正文、列表和标题层级正常；即刻/X 无限滚动无控制台错误；关闭扩展后原页面可恢复。
