<h1 align="center">舒读 · ADHD 网页阅读器</h1>

<p align="center">让微信公众号、AI 内参、即刻、X / Twitter 和普通长文在显示器上更宽、更清楚、更容易抓住重点。</p>

舒读是一个本地运行的 Manifest V3 浏览器扩展，适用于 Tabbit、Chrome、Edge 等 Chromium 浏览器。它重排正文宽度与字号层级，提供更适合中文长文的字体、行距和段落节奏，并用半高透明马克笔区分重点、概念、行动、证据和程度词。

当前版本：**0.4.4**

## 功能

- 微信公众号正文宽度最高可调至 2400 px；窄窗口自动保留安全边距。
- AI 内参文章页自动突破原有 `max-w-3xl` 窄栏，同时保留左侧日历、顶部导航和笔记侧栏。
- 正文、列表、章节标题与多级标题使用独立字号阶梯，修复公众号原排版里标题反而更小的问题。
- 提供轻盈、专注、沉浸三种预设，也可独立调整字号、行距与段落间距。
- 本地规则自动加粗关键词，并以黄、蓝、绿、紫、粉五种低透明度浅标记区分语义；动态页面使用无下划线的透明浅底色，静态页面保留半高马克笔效果。
- 自动折叠公众号里的空段和无装饰间隔容器。
- 可选的段落聚焦只显示淡色左侧引导线，不再给整篇文章添加背景蒙版。
- 即刻与 X / Twitter 使用无侵入的 CSS Highlight API，不替换 React 页面文字节点。
- 普通长文优先识别 `article`、`articleBody`、`post-body`、`story-body`、`prose`、`markdown-body` 等真实正文容器；英文标题不再叠加马克笔，英文标记比中文更薄、更浅。
- 可选的「智能译读」按阅读位置逐段补译，支持滚动时处理动态新增内容和 `⌥ + ⇧ + F` 快捷键。
- 译读会识别没有 `<p>` 包裹的首段文本，并明确提示「当前屏无候选」「接口漏返」或「正在处理」。
- 默认按大学英语六级 524 分（约 B2）筛选每段 3–5 个 B2+/C1 表达；基础词会在模型输出后再过滤。
- 漏段会自动缩小批次重试：先按 6 段、再按 3 段、最后逐段补齐；本地缓存避免重复付费。
- 排版和语义强调始终在本地运行；只有主动开启智能译读时，当前阅读区的英文段落才会发送给用户自己配置的智谱 API。

## 智能译读

1. 打开舒读面板，展开「智谱 API 设置」。
2. 填入智谱开放平台通用 API Key。Key 仅保存在 `chrome.storage.local`，不会写入源码、GitHub 或跨设备同步。
3. 模型默认使用官方当前文档可确认的 `glm-5.2`；模型代码可以手动修改。
4. 点击「保存并测试」，连接成功后点击「开启滚动译读」。继续往下阅读时，新进入屏幕的英文段落会自动补译。

智能译读使用标准开放平台端点 `https://open.bigmodel.cn/api/paas/v4/chat/completions`。GLM Coding Plan 的 `/api/coding/...` 端点由官方限定给支持的编程工具，不用于本扩展。

## 安装

1. 下载或克隆本仓库。
2. 在浏览器地址栏打开 `chrome://extensions/`。
3. 打开「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择本仓库文件夹。
5. 刷新已经打开的公众号、AI 内参、即刻或 X / Twitter 页面。

```bash
git clone https://github.com/reneexiaoxiao/shudu-adhd-reader.git
```

普通 HTTP(S) 文章页不会自动运行：打开「舒读」面板，点击「应用当前页面」即可临时启用。

## 字体说明

公开仓库不包含「中华薪火体」字体文件，避免未经授权再分发第三方字库。扩展会先检测系统已安装的 `Sino-Torch` / `中华薪火体`，不可用时自动回退到苹方等系统字体。

如果你拥有该字体的合法授权，可将文件放到：

```text
fonts/中华薪火体.ttf
```

然后在扩展管理页点击「重新加载」。其他字体选项依赖操作系统已安装字体。

## 语义颜色

| 颜色 | 语义 |
| --- | --- |
| 黄色 | 重点、结论、本质 |
| 蓝色 | 概念、模型、方法与专有名词 |
| 绿色 | 行动、要求、建议与下一步 |
| 紫色 | 数字、证据、研究与案例 |
| 粉色 | 程度、层级与比较词 |

语义强调使用轻量本地规则，不等同于大模型理解；它优先保证隐私、速度与可预测性。

## 权限与隐私

- `storage`：保存阅读设置。
- `activeTab` 与 `scripting`：在你点击「应用当前页面」后处理当前标签页。
- 站点权限：让公众号、AI 内参、即刻和 X / Twitter 自动应用排版。

- `open.bigmodel.cn`：仅在用户主动开启智能译读或点击连接测试时调用智谱 API。

扩展不包含自建服务器、账户系统、广告、分析 SDK 或遥测。完整说明见 [PRIVACY.md](PRIVACY.md)。

## 开发与验证

项目不需要构建步骤，修改源码后在 `chrome://extensions/` 点击「重新加载」即可。核心文件：

- `content.js`：站点识别、排版与本地语义强调。
- `reader.css`：阅读版式、字体层级与马克笔效果。
- `translation-core.js`、`translation.js`、`translation.css`：段落识别、分级英文保留、动态补译与呈现。
- `background.js`：从扩展后台调用智谱 API；API Key 不进入网页上下文。
- `popup.*`：设置面板。
- `manifest.json`：Manifest V3 权限与入口。

提交前至少确认：公众号正文、列表和标题层级正常；即刻/X 无限滚动无控制台错误；智能译读不重复、不漏段、不改写原文；关闭扩展后原页面可恢复。
